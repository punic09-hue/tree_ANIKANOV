# Род Аникановых — родословное исследование

Сельцо Бегино (Ступишино) Одоевского уезда Тульской губернии → Плавск · Москва · Тула · Свердловск. Сайт — статический (GitHub Pages, ветка main, корень).

- Сведения о людях, родившихся после 1925 года, и об их потомках не публикуются.
- Каждый факт снабжён ссылкой на источник реестра (S01…) или помечен как предположение.
- Данные собираются из базы исследования: `python3 tools/build_from_anikanovy.py <папка anikanovy_import>` (затем вручную правится только `data/milestones.js`).
